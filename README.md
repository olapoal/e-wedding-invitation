# 💍 Aplikasi Generate Electronic Wedding Invitation Tercanggih

Aplikasi web modern, mewah, dan berfitur lengkap untuk membuat **Undangan Pernikahan Elektronik Digital Kustom** dengan sistem monetisasi terintegrasi via **Lynk.id** dan sistem isi ulang token via **Trakteer**.

Aplikasi ini dirancang khusus untuk calon pengantin maupun vendor/wedding organizer dengan tampilan elegan, interaktif, mudah digunakan, dan kaya fitur.

---

- **Input Cepat Satuan & Massal**:
  - Masukkan nama tamu dan nomor WhatsApp secara langsung.
  - Mendukung impor massal / *copy-paste* dari Microsoft Excel atau Google Sheets (Format: `Nama Tamu, Nomor WA`).

  - Format lokal `0812...`, `+628...`, `8...` otomatis dikonversi ke standar internasional `62812...`.

  - Indikator status `[⚪ Belum Dikirim]` dan `[✅ Sudah Dikirim]` yang otomatis aktif saat tombol kirim diklik.
  - Daftar tamu tersimpan aman di browser (`localStorage`) sehingga tidak hilang saat berpindah tab atau refresh.
  - Tombol ringkasan: *Salin Seluruh Link*, *Salin Pesan Tamu*, dan *Kosongkan Daftar*.

## 🔒 Sistem Akses Lynk.id & Lock Screen

Aplikasi ini diproteksi menggunakan sistem **Lock Screen Lynk.id**:

1. **Pembelian**: Pembeli membeli produk generator undangan di toko Lynk.id Anda (misal: `https://lynk.id/olapoal`).
2. **Buka Akses**: Pembeli membuka aplikasi dan memasukkan email yang digunakan saat bertransaksi di Lynk.id.
3. **Verifikasi**: Sistem memeriksa status pembayaran pembeli via serverless endpoint `/api/verify-email`.
4. **Login Tersimpan**: Akses otomatis tersimpan di browser (`localStorage`), sehingga pembeli tidak perlu login berulang kali.
5. **Mode Demo Pengembang**: Tersedia tombol *"Coba Mode Demo Offline"* untuk pengujian langsung tanpa perlu terhubung ke server.

## 🪙 Sistem Token Publikasi & Integrasi Top-Up Trakteer

### 💡 Konsep Token Publikasi:
- Setiap kali pengguna mempublikasikan 1 undangan baru secara online, sistem akan mengonsumsi **1 Token**.
- **Konfirmasi Transparan**: Sebelum memotong token, aplikasi memunculkan jendela konfirmasi yang menampilkan sisa token saat ini dan sisa token setelah publish.
- **Update Gratis**: Mengedit atau memperbarui undangan pada tautan (slug) yang sama **tidak memotong token lagi**.
- **Jika Token Habis**: Tombol publish otomatis memblokir dan mengarahkan pengguna ke jendela Top-Up Trakteer.

---

### 🥤 Cara Kerja Otomatisasi Token Trakteer (Pikirkan Caranya):

Kami merancang **3 Lapis Sistem Verifikasi Otomatis** yang andal:

```
[Pengguna Trakteer]
       │
       ▼
1. Tipping Cendol di Trakteer (1 Cendol = 1 Token)
   Supporter menuliskan EMAIL terdaftar di catatan Trakteer
       │
       ├─────────────────────────────────────────┐
       ▼                                         ▼
[METODE A: WEBHOOK REALTIME]            [METODE B: VERIFIKASI INSTAN DALAM APP]
Trakteer mengirim notifikasi ke:        Pengguna klik "Cek Status Token"
/api/trakteer-webhook                   atau memasukkan Order ID Trakteer
       │                                         │
       ▼                                         ▼
Sistem membaca Supporter Email          Sistem mencocokkan ke database/API
& menambahkan token otomatis!           Token langsung dikreditkan + muncul confetti!
```

#### A. Webhook Otomatis Realtime (`/api/trakteer-webhook`):
1. Pengguna membuka halaman Trakteer Anda dan membeli paket (misal 1, 3, atau 5 Cendol).
2. Pengguna mencantumkan email terdaftarnya di kolom catatan supporter Trakteer.
3. Trakteer mengirim webhook POST ke endpoint `/.netlify/functions/trakteer-webhook`.
4. Sistem serverless mengekstrak email dan jumlah unit/cendol, lalu secara otomatis mengkreditkan saldo token ke profil pengguna di Netlify Blobs database.

#### B. Pengecekan Mandiri Instan (`/api/verify-trakteer`):
- Jika pengguna telah menyelesaikan pembayaran namun ingin tokennya langsung aktif tanpa menunggu, pengguna dapat menekan tombol **"Cek Status Token"** atau memasukkan Kode Transaksi / Order ID Trakteer di modal top-up.
- Sistem akan memvalidasi transaksi dan langsung memperbarui saldo token di layar secara *realtime*.

#### C. Kontrol Master Admin (`admin.html`):
- Pemilik website dapat menambah/mengurangi saldo token untuk email mana pun kapan saja dengan 1 klik melalui Dashboard Admin.

## 🚀 Panduan Menjalankan & Menguji Aplikasi

### Cara 1: Uji Coba Offline Langsung di Browser (Tanpa Server)
1. Buka file **[`index.html`](file:///G:/My%20Drive/Personal/Project/Aplikasi%20E-Wedding%20Invitation/index.html)** langsung dengan klik ganda di Google Chrome atau Microsoft Edge.
2. Pada layar pembuka lisensi, klik tombol **"⏱️ Coba Mode Demo Gratis (2 Menit + Live Countdown)"**.
3. Sesi uji coba 2 menit akan aktif dengan **Live Countdown Timer** di navbar atas. Saat waktu habis, akses akan terkunci otomatis dan mengarahkan pengguna untuk membeli lisensi di Lynk.id!
4. Buka **[`admin.html`](file:///G:/My%20Drive/Personal/Project/Aplikasi%20E-Wedding%20Invitation/admin.html)** untuk menguji panel admin dengan password default: `admin12345`.

---

### Cara 2: Menghubungkan ke Netlify (Deploy Online Gratis)

1. **Deploy ke Netlify**:
   - Tarik folder ini ke Netlify Dashboard atau hubungkan via GitHub / Netlify CLI (`netlify deploy --prod`).
2. **Pengaturan Environment Variables di Netlify**:
   Buka menu **Site Configuration** &gt; **Environment variables**:
   - `ADMIN_EMAILS` : `olapoal.artgallery@gmail.com,admin@wedding.com`
   - `ADMIN_PASSWORD` : `admin12345` (atau ganti dengan password rahasia Anda)
   - `TRAKTEER_API_KEY` : *(Opsional) Kunci API dari dashboard Trakteer Anda*
   - `SUPABASE_URL` / `SUPABASE_KEY` : *(Opsional jika ingin dual backup dengan Supabase)*

3. **Konfigurasi Webhook di Dashboard Lynk.id**:
   - URL Webhook: `https://<nama-aplikasi>.netlify.app/.netlify/functions/lynk-webhook`
   - Event: `Payment Success` / `Order Paid`

4. **Konfigurasi Webhook di Dashboard Trakteer**:
   - Buka menu **Integrasi** / **Webhook** di Trakteer Creator.
   - URL Webhook: `https://<nama-aplikasi>.netlify.app/.netlify/functions/trakteer-webhook`
   - Event: `Tip / Support`
